# 구현 계획 - spec-viewer-doc-modified-date

## 정의
스펙 문서의 진행 상태를 트리에서 훑어보는 spec-viewer 사용자를 위해, 문서 행에 최종 수정일을 흐리게 보여 주는 기능을 구현 단위로 나눈 실행 계획이다.

- [x] 1. 수정 시각 수집과 날짜 문자열
- [x] 1.1 수정 시각을 담는 자리와 날짜 문자열 만들기
  - 실패하는 단위 테스트부터: 수정 시각의 로컬 날짜가 `YYYY-MM-DD` 10자로 나오고 기존 일시 문자열의 날짜 부분과 같다
  - 문서 항목과 파일 스냅숏에 수정 시각 자리를 추가하고, 스냅숏을 읽을 때 각 파일의 수정 시각을 담는다(읽기 실패는 비어 있음으로 처리)
  - 새 자리가 생기면서 컴파일이 깨지는 기존 테스트용 문서 항목과 스냅숏 생성 코드도 함께 보충한다(값은 비어 있음)
  - _DoneWhen: 날짜 문자열 단위 테스트와, 실제 파일을 읽은 스냅숏의 모든 파일이 수정 시각을 갖는다는 통합 테스트가 통과하고 기존 테스트가 컴파일된다_
  - _Requirements: 1.1, 1.4, 1.6, 2.1_
  - _Difficulty: mid_
  - _Boundary: spec 문서 항목 타입(타입 정의와 테스트 픽스처), app::loader_
- [x] 1.2 `.kiro` 문서 항목으로 수정 시각 전달
  - 실패하는 단위 테스트부터: 스냅숏의 수정 시각이 표준 문서, 연구 문서, 그 밖의 문서 항목에 그대로 옮겨지고 파일이 없는 자리는 비어 있다
  - _DoneWhen: 문서 항목 조립 테스트에서 존재하는 문서만 수정 시각을 갖고 미생성 자리는 비어 있다_
  - _Requirements: 1.1, 1.3, 2.2_
  - _Difficulty: low_
  - _Boundary: spec 문서 항목 타입(문서 항목 조립)_
  - _Depends: 1.1_
- [x] 1.3 spec-kit 문서 항목에 수정 시각 싣기
  - 실패하는 단위 테스트부터: 표준 문서, `tasks.md`, `contracts/`, 그 밖의 문서 항목이 실제 파일의 수정 시각을 갖는다
  - _DoneWhen: 임시 디렉터리에 만든 spec-kit 기능의 모든 문서 항목이 수정 시각을 갖는 테스트가 통과한다_
  - _Requirements: 1.2, 1.4, 2.1_
  - _Difficulty: low_
  - _Boundary: spec::spec_kit_
  - _Depends: 1.1_

- [x] 2. 트리 표시
- [x] 2.1 문서 행 끝에 흐린 날짜 표시
  - 실패하는 렌더 테스트부터: 날짜가 있는 문서 행에 파일명 뒤로 날짜가 나오고, 진행률이 있는 `tasks.md` 행은 진행률 뒤에 나오며, 날짜가 없는 행에는 아무것도 덧붙지 않는다
  - 일치 강조가 날짜 구간에도 적용되고 스펙 행과 파일 트리 행 생성은 바뀌지 않는다
  - _DoneWhen: 렌더된 화면 버퍼에서 문서 행의 파일명 뒤에 흐린 날짜가 보이고, 미생성 행과 날짜 없는 행은 변경 전과 같으며, 기존 트리 테스트가 전부 통과한다_
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5, 1.6, 1.7, 3.1, 3.2_
  - _Difficulty: mid_
  - _Boundary: ui::tree_panel_
  - _Depends: 1.2, 1.3_

- [x] 3. 검증
- [x] 3.1 갱신 반영과 읽기 전용 확인
  - 문서 파일을 수정한 뒤 다시 만든 트리의 날짜가 바뀌고, 삭제하면 미생성 표시와 함께 날짜가 사라지는 흐름을 검증한다
  - 수집 과정이 감시 대상 디렉터리에 파일을 만들거나 바꾸지 않음을 확인한다
  - _DoneWhen: 수정 후 새로고침 시 행의 날짜가 새 날짜로 렌더되고, 삭제 후에는 날짜가 사라지며, 수집 전후 디렉터리 내용이 같다는 테스트가 통과한다_
  - _Requirements: 2.1, 2.2, 3.3_
  - _Difficulty: mid_
  - _Depends: 2.1_
- [x] 3.2 전체 회귀와 실행 확인
  - 전체 테스트 스위트를 통과시키고, 빌드한 실행 파일(`cargo run`)로 `.kiro` 스펙을 펼쳐 문서 행의 날짜를 눈으로 확인한다
  - _DoneWhen: 전체 테스트가 통과하고 실제 화면에서 문서 행 끝에 흐린 날짜가 보인다_
  - _Requirements: 1.7, 3.1_
  - _Difficulty: low_
  - _Depends: 3.1_
