# BizProcess — spec-viewer-editor-mode

## 정의
개발자를 위해 문서 패널에서 편집 키를 눌러 외부 에디터로 전환했다가 저장·종료 후 뷰어로 돌아오는 흐름을 L1~L6로 전개한 사용자 시각 프로세스이다.

## 가치사슬 매핑

| L1 Process | Unit Process (valueChainRef) | 가치 | 관련 요구사항 |
|------------|------------------------------|------|---------------|
| BP-SPEC-EDIT | VC-DEV-SPEC-EDIT | 뷰어에서 발견한 문제를 그 자리에서 바로 고친다 | 1 ~ 6 |

## L1 Process: 문서 즉시 편집  (id: BP-SPEC-EDIT, valueChainRef: VC-DEV-SPEC-EDIT)

개발자가 문서 패널에서 읽던 문서를 편집 키 한 번으로 에디터에 넘기고, 고친 뒤 저장·종료하면 뷰어 화면으로 돌아와 바뀐 내용을 바로 확인한다.

```
L2-B1 Activity: 편집모드 진입  (1.1, 1.3)
  L3-F1 UI: 문서 패널 + 편집 키
    L4-S1 Step: 편집 키를 입력한다
      L5-D1 DetailStep: 문서 패널에 편집 가능한 파일이 표시돼 있다
        Logic(AST):
          - IF 문서 패널이 파일 하나를 표시 중(포커스 위치 무관) THEN 화면이 일시 중단되고 그 파일 경로로 에디터가 열린다
      L5-D2 DetailStep: 문서 패널이 편집 불가 상태다
        Logic(AST):
          - IF 문서 패널이 비어 있음 OR 스펙 정의 요약 화면 OR 표시 불가(누락/삭제됨/읽기 오류/메타 오류) THEN 개발자는 상태 표시줄에서 "편집할 파일 없음" 안내를 본다
          - 편집은 시작되지 않는다

L2-B2 Activity: 에디터 선택  (2.1~2.4)
  L3-F2 UI: (화면 없음 — 개발자는 결과로 어떤 에디터가 열렸는지만 본다)
    L4-S2 Step: 실행될 에디터가 정해진다
      L5-D3 DetailStep: 우선순위에 따라 결정된다
        Logic(AST):
          - IF `--editor` 옵션 지정 THEN 그 명령을 실행한다
          - ELSE IF `$VISUAL` 설정됨 THEN `$VISUAL` 값을 실행한다
          - ELSE IF `$EDITOR` 설정됨 THEN `$EDITOR` 값을 실행한다
          - ELSE `vi` 를 실행한다

L2-B3 Activity: 화면 복귀와 반영  (1.2, 3.1~3.3)
  L3-F3 UI: 에디터 종료 → 뷰어 화면
    L4-S3 Step: 에디터가 끝나고 뷰어로 돌아온다
      L5-D4 DetailStep: 화면 상태가 복원된다
        Logic(AST):
          - 항상: 입력 모드·마우스 조작 가능 여부가 편집 시작 전과 동일하게 복원되고 화면이 다시 그려진다
      L5-D5 DetailStep: 파일 변경 감시가 켜져 있다
        Logic(AST):
          - IF 파일이 바뀜 THEN 개발자는 별도 조작 없이 바뀐 내용을 보고, 가능하면 이전 스크롤 위치 근처가 유지된다
          - ELSE(저장 안 함) 개발자는 편집 전과 같은 내용을 본다
      L5-D6 DetailStep: `--no-watch` 로 감시가 꺼져 있다
        Logic(AST):
          - IF 감시 꺼짐 THEN 자동 반영 없이, 개발자는 상태 표시줄에서 수동 새로고침 키 안내를 본다

L2-B4 Activity: 오류 상황 처리  (4.1, 4.2)
  L3-F4 UI: 오류 메시지
    L4-S4 Step: 에디터 실행·종료가 정상적이지 않다
      L5-D7 DetailStep: 에디터를 실행할 수 없다
        Logic(AST):
          - IF 지정/폴백된 에디터 명령 실행 실패 THEN 화면이 정상 복원되고 개발자는 실행 실패 메시지를 본다
          - 뷰어는 계속 동작한다
      L5-D8 DetailStep: 에디터가 비정상 종료 코드로 끝난다
        Logic(AST):
          - IF 비정상 종료 THEN 화면이 정상 복원되고 개발자는 경고 메시지를 본다
          - 이후 반영 여부는 L2-B3 규칙(파일 변경 여부)을 그대로 따른다

L2-B5 Activity: 진입 전 상태 유지  (5.1, 5.2)
  L3-F5 UI: (화면 없음 — 개발자는 결과로만 관찰)
    L4-S5 Step: 편집 전후 상태가 이어진다
      L5-D9 DetailStep: 진입 전에 마우스 조작이 이미 꺼져 있었다
        Logic(AST):
          - IF 편집모드 진입 시점에 마우스 조작이 비활성 상태 THEN 복귀 후에도 다시 켜지 않는다
      L5-D10 DetailStep: 편집 중에는 뷰어가 멈춰 있다
        Logic(AST):
          - 항상: 편집모드 진입부터 에디터 종료까지 다른 키 입력과 화면 갱신은 처리되지 않는다

L2-B6 Activity: 도움말에서 발견  (6.1)
  L3-F6 UI: 도움말 화면
    L4-S6 Step: 도움말을 연다
      L5-D11 DetailStep: 편집 키 설명을 본다
        Logic(AST):
          - 항상: 편집 키와 설명이 다른 키와 같은 방식으로 함께 표시된다
```
