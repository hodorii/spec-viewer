# Requirements — spec-viewer-editor-mode

## 정의
spec-viewer 사용자를 위해 문서 패널에 표시된 파일을 외부 에디터(vi/vim 등)로 열고, 편집을 마치면 자동으로 뷰어 화면으로 돌아와 반영된 내용을 다시 보여주는 편집모드 전환 기능이다.

## Boundary Context
- **In scope**: 문서 패널에 현재 표시된 파일(스펙 문서·steering 문서·`--all` 모드 마크다운 파일 포함)을 외부 에디터로 열고 돌아오는 것, 에디터 선택 우선순위(`$VISUAL`/`$EDITOR`/`vi`, `--editor` 옵션), 편집 후 기존 파일 감시 경로를 통한 자동 재렌더, 에디터 실행·종료 관련 오류 처리, 도움말 노출.
- **Out of scope**: 뷰어 자체가 문서 내용을 직접 편집하는 기능, `spec.json` 승인 상태·기타 `.kiro/` 메타데이터 변경, 동시에 둘 이상의 파일 편집, 스펙 정의 요약 화면 편집, 외부 에디터 내부 동작(문법 강조·플러그인 등)에 대한 관여.

## Acceptance Criteria

### 1. 편집모드 진입과 복귀
- 1.1: [문서 패널에 편집 가능한 파일이 표시된 상태에서 편집 키 입력, 포커스 위치 무관] → 화면이 일시 중단되고 그 파일 경로로 에디터가 실행됨.
- 1.2: [에디터가 종료됨(정상·비정상 종료 모두)] → 화면 상태(입력 모드·마우스 조작 가능 여부 포함)가 편집 시작 전과 동일하게 복원되고 다시 그려짐.
- 1.3: [문서 패널이 비어 있거나, 스펙 정의 요약 화면이거나, 문서를 표시할 수 없는 상태(누락·삭제됨·읽기 오류·메타 오류)일 때 편집 키 입력] → 편집이 시작되지 않고 상태 표시줄에 편집할 파일이 없다는 안내가 표시됨.

### 2. 에디터 선택
- 2.1: [`--editor <명령>` 옵션이 지정됨] → 환경변수보다 우선해 그 명령을 에디터로 실행.
- 2.2: [`--editor` 미지정, `$VISUAL` 환경변수 설정됨] → `$VISUAL` 값을 에디터로 실행.
- 2.3: [`--editor`·`$VISUAL` 모두 없음, `$EDITOR` 환경변수 설정됨] → `$EDITOR` 값을 에디터로 실행.
- 2.4: [`--editor`·`$VISUAL`·`$EDITOR` 모두 없음] → `vi`를 에디터로 실행.

### 3. 편집 후 반영
- 3.1: [파일 변경 감시가 활성 상태에서 에디터가 파일을 저장하고 정상 종료] → 별도 조작 없이 자동으로 다시 렌더링되고, 가능한 경우 이전 스크롤 위치 근처가 유지됨.
- 3.2: [`--no-watch`로 감시가 꺼진 상태에서 에디터 종료] → 자동 재렌더링이 일어나지 않으며, 수동 새로고침 키로 갱신할 수 있음이 상태 표시줄에 표시됨(기존 감시 꺼짐 표시와 동일).
- 3.3: [에디터가 파일을 저장하지 않고 종료] → 문서 내용이 편집 시작 전과 동일하게 유지됨.

### 4. 오류 처리
- 4.1: [지정되거나 폴백된 에디터 명령을 실행할 수 없음] → 화면이 정상 복원되고 실행 실패를 알리는 메시지가 표시되며, 뷰어는 계속 동작함.
- 4.2: [에디터가 비정상 종료 코드로 종료] → 화면이 정상 복원되고 경고 메시지가 표시되되, 이후 재렌더링 여부는 실제 파일 변경 여부에 따라 3.1·3.3과 동일하게 결정됨.

### 5. 편집 중 상태 일관성
- 5.1: [편집모드 진입 시점에 마우스 조작이 이미 비활성 상태(캡처 실패로 강등됨)] → 에디터 종료 후 복귀해도 마우스 조작은 다시 활성화되지 않음.
- 5.2: [편집모드 진입부터 에디터 종료까지] → 다른 키 입력과 화면 갱신은 처리되지 않으며, 에디터 종료 후에만 재개됨.

### 6. 도움말 노출
- 6.1: [도움말 화면 호출] → 편집모드로 진입하는 키와 그 설명이 다른 키와 같은 방식으로 함께 표시됨.
