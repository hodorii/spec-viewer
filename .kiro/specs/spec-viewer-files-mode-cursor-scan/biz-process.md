## 소유 파일 append 사양  (BP-SPEC-VIEW; valueChainRef: VC-DEV-SPEC-VIEW)

### L2-A1 "뷰어 열기" 아래 L4-S1의 L5 DetailStep 교체  (관련 요구사항: 2.1, 2.2, 2.3)

**L5-D1 교체**: "경로 없이 실행한다" (기존 유지)
**L5-D2 교체**: "경로를 지정해 실행한다" (기존 유지)
**L5-D3 신규**: "파일 모드로 시작한다"
- `--files [path]`로 실행하면 `[path]`(생략 시 현재 작업 디렉터리)를 뿌리로 파일 모드가 열린다
- `--all`을 그대로 쓰면 "미지원 플래그" 오류와 함께 뷰어가 열리지 않는다
- `--help`를 보면 `--files`가 있고 `--all`은 어떤 형태로도 보이지 않는다

### L2-A7 "일반 마크다운 폴더 탐색(`--all`)" Activity 이름 교체  (관련 요구사항: 2.1~2.3)

**신규 이름**: "파일 모드로 탐색"
- Activity 본문의 `--all` 언급은 전부 `--files`로 바뀐다
- 파일 모드의 깊이 상한은 이름 변경 전과 동일하고, 숨김 파일 규칙은 뿌리 바로 아래 `.kiro` 폴더를 포함하는 예외(BR-SPEC-VIEW-001)를 빼면 동일하다

### L2-A8 "모드 전환" Activity 신규  (관련 요구사항: 1.1~1.4, 3.1~3.5, 4.1)

승인된 append 사양(L2-A8 모드 전환, BR-SPEC-VIEW-001~010)은 소유 파일 `.kiro/specs/spec-viewer/biz-process.md` 에 반영되었고, 규칙 정의는 그 파일이 유일한 출처이다.
