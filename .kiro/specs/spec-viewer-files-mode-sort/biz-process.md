## L1 Process: `--all` 모드 정렬 지원  (id: BP-FILES-SORT, valueChainRef: VC-DEV-SPEC-VIEW)

개발자가 `--all` 모드로 순수 마크다운 폴더를 열었을 때, `.kiro` 모드와 같은 정렬 키로 파일을 더 빠르게 찾는다.

```
L2-D1 Activity: --all 모드 정렬 순환  (1.1~1.4)
  L3-H1 UI: 트리 패널(정렬 순환 키)
    L4-S1 Step: 정렬 순환 키를 입력한다
      L5-D1 DetailStep: --all 모드에서
        Logic(AST):
          - 정렬 키가 이름과 최근 수정 사이에서만 순환한다(1.1)
          - 이름 정렬이면 형제 항목이 이름 오름차순으로 보인다(1.2)
          - 최근 수정 정렬이면 형제 항목이 최근 수정순으로 보인다(1.3)
      L5-D2 DetailStep: --sort로 .kiro 전용 키를 지정하고 --all로 시작한다
        Logic(AST):
          - 오류 없이 이름 정렬로 시작한다(1.4)

L2-D2 Activity: 트리 구조 유지  (2.1~2.2)
  L3-H1 UI: 트리 패널(정렬 순환 키)
    L4-S2 Step: 정렬 키를 바꾼다
      L5-D3 DetailStep: 항상
        Logic(AST):
          - 폴더-하위항목 포함 관계는 그대로이고 형제 순서만 바뀐다(2.1)
          - 펼침·선택 상태는 유지된다(2.2)

L2-D3 Activity: 정렬 키 표시  (3.1)
  L3-H2 UI: 트리 패널(제목)
    L4-S3 Step: 트리 패널을 본다
      L5-D4 DetailStep: --all 모드에서
        Logic(AST):
          - 패널 제목에 현재 정렬 키가 보인다(3.1)

L2-D4 Activity: 기존 동작 무회귀  (4.1~4.3)
  L3-H3 UI: (화면 없음 — 개발자는 결과로만 관찰)
    L4-S4 Step: .kiro 모드나 spec-kit 모드를 쓴다 / 자동 발견된 그룹을 본다
      L5-D5 DetailStep: 항상
        Logic(AST):
          - .kiro 모드의 4단 순환과 결과는 그대로다(4.1)
          - spec-kit 모드는 영향받지 않는다(4.2)
          - 자동 발견된 그룹(steering 등) 안 순서는 그대로다(4.3)
```
