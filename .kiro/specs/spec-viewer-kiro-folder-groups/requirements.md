# Requirements — spec-viewer-kiro-folder-groups

## 정의
spec-viewer 사용자를 위해 `.kiro` 프로젝트의 `specs` 외 임의의 하위 폴더(예: `steering`, `reference`, `guide`)도 자동으로 발견해 하위 폴더까지 트리에서 탐색할 수 있게 하는 기능이다.

## Boundary Context
- **In scope**: `.kiro` 모드에서 `specs`를 제외한 모든 하위 폴더 중 마크다운 문서를 포함한 폴더의 자동 발견과 표시, 그 안의 하위 폴더까지 포함한 탐색, 기존 `steering` 문서의 포함 방식(inclusion) 표시 유지, 기존 문서 열람·검색·편집·감시 기능과의 통합.
- **Out of scope**: GitHub spec-kit(`.specify/`) 모드의 동등 기능, `specs` 자체의 표시 방식 변경, 트리 레이아웃 모드·정렬 키·전체 모드/스펙 모드 전환·전체펼치기/전체접기 키 자체의 정의 변경(기존 동작에 새 폴더도 참여할 뿐).

## Acceptance Criteria

### 1. 폴더 자동 발견
- 1.1: [`.kiro` 아래 `specs`가 아닌 하위 폴더 안에(하위 폴더 포함) 마크다운 문서가 하나 이상 있음] → 그 폴더가 자신의 이름을 단 그룹으로 트리에 나타남.
- 1.2: [`.kiro` 아래 `specs`가 아닌 하위 폴더 안에 마크다운 문서가 전혀 없음] → 그 폴더는 트리에 나타나지 않음.
- 1.3: [`.kiro` 아래 마크다운 문서를 포함한 하위 폴더가 여럿 존재함] → 모든 폴더가 각자의 그룹으로 동시에 트리에 나타남.
- 1.4: [항상] → `specs` 폴더는 이 자동 발견 대상이 아니며 기존 스펙 트리 방식으로만 표시됨.
- 1.5: [마크다운 문서를 포함한 하위 폴더가 여럿 존재함] → 그룹들은 실행마다 일관된 순서로 표시됨.
- 1.6: [`.kiro` 아래 `specs` 외의 폴더가 하나도 없거나 전부 마크다운이 없음] → 기존과 동일하게 스펙 트리만 표시되고 오류가 없음.

### 2. 하위 폴더까지 탐색
- 2.1: [자동 발견된 그룹 폴더 안에 하위 폴더가 있음] → 그 하위 폴더를 트리에서 펼쳐 안의 문서를 볼 수 있음.
- 2.2: [자동 발견된 그룹 폴더 안의 하위 폴더 안에 또 하위 폴더가 있음] → 몇 단계든 계속 펼쳐 들어갈 수 있음.
- 2.3: [`steering`이라는 이름의 폴더 안에 하위 폴더가 있음] → `steering`도 다른 자동 발견 그룹과 동일하게 하위 폴더를 펼쳐볼 수 있음.
- 2.4: [그룹 노드 또는 그 하위 폴더 노드를 펼치거나 접음] → 그 노드의 직계 한 단계만 펼쳐지거나 접히며, 재귀적으로 다른 단계까지 함께 바뀌지 않음.

### 3. `steering` 표시 방식 무회귀
- 3.1: [`steering`이라는 이름의 폴더 바로 아래에 있는 마크다운 문서] → 기존과 동일하게 포함 방식(always/manual/fileMatch/auto) 표시가 함께 보임.
- 3.2: [`steering`이 아닌 이름의 자동 발견 그룹 안에 있는 마크다운 문서] → 포함 방식 표시 없이 일반 문서로 보임.

### 4. 기존 기능과의 통합
- 4.1: [자동 발견된 그룹 안의 문서를 선택함] → 문서 패널에 그 문서의 렌더링된 내용이 표시됨.
- 4.2: [자동 발견된 그룹 안의 문서를 대상으로 검색함] → 트리 이름 검색과 문서 내용 검색이 스펙·`steering` 문서와 동일하게 동작함.
- 4.3: [문서 패널에 자동 발견된 그룹의 문서가 표시된 상태에서 편집 키 입력] → 기존 문서 편집 기능과 동일하게 외부 에디터가 열리고 저장 시 반영됨.
- 4.4: [전체펼치기/전체접기 키 입력] → 자동 발견된 모든 그룹과 그 하위 폴더도 스펙·`steering` 노드와 함께 펼쳐지거나 접힘.
- 4.5: [파일 감시가 켜진 상태에서 자동 발견된 그룹 폴더 아래 파일이 추가·수정·삭제됨] → 트리와 문서 패널이 기존 감시 동작과 동일하게 자동으로 갱신됨.

### 5. 모드 경계
- 5.1: [GitHub spec-kit(`.specify/`) 모드로 실행 중] → 이 기능의 영향을 받지 않으며 spec-kit 모드의 트리 표시는 그대로임.
