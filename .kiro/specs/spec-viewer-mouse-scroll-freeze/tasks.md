# Implementation Plan — spec-viewer-mouse-scroll-freeze

## 정의
마우스 모션 이벤트의 원천 차단과 입력 버스트 병합으로, 마우스 스크롤이 키보드 스크롤과 동일하게 즉시 반응하게 하는 수정을 재현 테스트로 고정하고 구현하는 최소 계획이다.

- [ ] 1. 결함 재현/불변 테스트 작성
- [ ] 1.1 활성화 시퀀스 재현 테스트: 마우스 캡처 활성화 시퀀스 생성부를 직렬화 가능한 단위로 추출하고, 그 출력이 모션 추적(`?1003h`)을 포함하지 않아야 함을 어서션하는 테스트를 추가 — 현재 시퀀스(1003h 포함)로 실패
  - DONE: 추출된 시퀀스 단위의 테스트(`mouse_capture_excludes_motion_tracking`)가 수정 전 현재 코드에서 실패함을 확인
  - _Requirements: 1.1, 2.2_
  - _Difficulty: low_
  - _Boundary: main_

- [ ] 1.2 (P) 불변 동작 고정 테스트: 모션 이벤트가 어떤 상태도 바꾸지 않음, 휠 이벤트가 트리 3행 선택 이동, 클릭·드래그·자동스크롤 제스처가 종전대로 동작함을 어서션하는 테스트 추가 (수정 전후 모두 통과)
