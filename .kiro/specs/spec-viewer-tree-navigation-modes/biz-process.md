# BizProcess — spec-viewer-tree-navigation-modes

## 정의
개발자를 위해 spec-viewer 실행 중 전체 모드와 스펙 모드를 오가고, 트리를 한 번에 펼치거나 접어 탐색을 빠르게 하는 사용자 시각 프로세스이다.

## 가치사슬 매핑

| L1 Process | Unit Process (valueChainRef) | 가치 | 관련 요구사항 |
|------------|------------------------------|------|---------------|
| BP-TREE-NAV | VC-DEV-SPEC-VIEW | 터미널에서 스펙·문서를 읽기 전용으로 빠르게 파악한다(트리 탐색 방식 자체를 개선해 "빠르게 파악" 가치를 강화) | 1 ~ 4 |

| 노드 | 이름 | 관련 요구사항 |

| L3-F4 | 도움말 화면 | 4.1 |

## L1 Process: 트리 탐색 개선  (id: BP-TREE-NAV, valueChainRef: VC-DEV-SPEC-VIEW)

개발자가 실행 중인 spec-viewer에서 모드를 바꾸거나 트리를 한 번에 펼치고 접어, 원하는 문서를 더 빠르게 찾는다.

```
L2-B1 Activity: 실행 중 모드 전환  (1.1~1.8)
  L3-F1 UI: 모드 전환 키
    L4-S1 Step: 모드 전환 키를 입력한다
      L5-D1 DetailStep: 스펙 모드에서 전체 모드로
        Logic(AST):
          - 항상 성공한다(전체 모드는 마커 유무와 무관, 1.1/1.3)
      L5-D2 DetailStep: 전체 모드에서 스펙 모드로
        Logic(AST):
          - IF 현재 위치 위로 .kiro 또는 .specify 마커를 찾음 THEN 그 우선순위 규칙대로 전환 성공(1.2)
          - ELSE 전환 거부, 상태 표시줄에 안내, 화면은 전환 전 그대로(1.4)
      L5-D3 DetailStep: 전환이 성공했다
        Logic(AST):
          - 파일 감시가 새 대상 디렉터리로 재시작된다(1.5)
          - 이전 트리의 펼침·선택 상태는 유지되지 않고 새 트리 초기 상태로 시작된다(1.6)
          - 문서 패널이 표시 중이었다면 초기 안내 상태로 돌아간다(1.7)
      L5-D4 DetailStep: `--all`로 시작했든 아니든
        Logic(AST):
          - 전환 키는 동일하게 동작한다(1.8)

L2-B2 Activity: 전체펼치기/전체접기  (2.1~2.4)
  L3-F2 UI: 전체펼치기/접기 키
    L4-S2 Step: 전체펼치기 또는 전체접기 키를 입력한다
      L5-D5 DetailStep: 노드가 있는 트리에서
        Logic(AST):
          - 전체펼치기 THEN 모든 폴더/스펙 노드가 펼쳐져 하위 문서·파일이 한 번에 보인다(2.1)
          - 전체접기 THEN 모든 노드가 접혀 최상위만 보인다(2.2)
          - 어느 쪽이든 선택 상태는 사라지지 않는다(2.3)
      L5-D6 DetailStep: 노드가 하나도 없는 트리에서
        Logic(AST):
          - 아무 효과 없이 정상 동작이 계속된다(2.4)

L2-B3 Activity: 기존 동작 유지  (3.1~3.2)
  L3-F3 UI: (화면 없음 — 개발자는 결과로만 관찰)
    L4-S3 Step: 개별 노드를 펼치거나 접는다 / `--all`로 시작한다
      L5-D7 DetailStep: 항상
        Logic(AST):
          - 개별 펼침·접힘은 이 기능 적용 전과 동일하게 1단계만 동작한다(3.1)
          - `--all`은 여전히 초기 모드 지정 용도로 동작한다(3.2)

L2-B4 Activity: 도움말에서 발견  (4.1)
  L3-F4 UI: 도움말 화면
    L4-S4 Step: 도움말을 연다
      L5-D8 DetailStep: 항상
        Logic(AST):
          - 모드 전환 키와 전체펼치기·전체접기 키가 다른 키와 같은 방식으로 표시된다
```
