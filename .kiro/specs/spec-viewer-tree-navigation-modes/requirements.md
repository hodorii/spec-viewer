# Requirements — spec-viewer-tree-navigation-modes

## 정의
spec-viewer 사용자를 위해 실행 중에 전체 모드와 스펙 모드를 전환하고, 트리를 한 번에 펼치거나 접을 수 있게 하는 트리 탐색 개선 기능이다.

## Boundary Context
- **In scope**: 실행 중 키 입력으로 전체 모드(`--all` 상당, 마크다운 디렉터리 트리)와 스펙 모드(`.kiro`/`.specify` 자동 인식) 전환, 전환 시 파일 감시 재시작, 전체펼치기/전체접기 토글 키, 도움말 노출.
- **Out of scope**: `TreeMode`(패널이 화면에서 차지하는 비율/표시 여부, `1`~`4` 키) 변경, 정렬 키(`SortKey`) 변경, 스펙 모드 안에서 `.kiro`와 spec-kit 사이의 전환(파일시스템 마커가 결정하는 것이지 사용자가 고르지 않음), 모드 전환 시 이전 트리의 선택/펼침/스크롤 상태를 새 트리로 승계하는 것.

## Acceptance Criteria

### 1. 실행 중 모드 전환
- 1.1: [스펙 모드로 실행 중, 모드 전환 키 입력] → 전체 모드로 전환되어 트리가 일반 마크다운 디렉터리 구조로 다시 표시됨.
- 1.2: [전체 모드로 실행 중, 모드 전환 키 입력] → 스펙 모드로 전환되어(`.kiro`/`.specify` 자동 인식 우선순위 규칙 그대로) 트리가 다시 표시됨.
- 1.3: [전체 모드로 전환하려 함] → 현재 위치에 `.kiro`/`.specify` 마커가 있는지와 무관하게 항상 전환에 성공함.
- 1.4: [스펙 모드로 전환하려 하나 현재 위치 위로 `.kiro`도 `.specify`도 찾을 수 없음] → 전환이 거부되고 상태 표시줄에 안내가 표시되며, 화면은 전환 시도 전 상태(전체 모드) 그대로 유지됨.
- 1.5: [모드가 성공적으로 전환됨] → 파일 감시가 새 모드의 대상 디렉터리를 기준으로 다시 시작되어, 이후 그 디렉터리 아래의 파일 변경이 감지됨.
- 1.6: [모드가 성공적으로 전환됨] → 이전 트리에서 펼쳐져 있던 노드나 선택 상태는 유지되지 않고, 새 트리의 초기 상태(선택 없음 또는 최상위 상태)로 시작됨.
- 1.7: [문서 패널에 파일이 표시된 상태에서 모드 전환] → 문서 패널은 초기 상태(안내 문구)로 돌아감.
- 1.8: [`--all` 플래그로 시작 vs `--all` 없이 시작] → 어느 쪽으로 시작했든 실행 중 모드 전환 키는 동일하게 동작함.

### 2. 전체펼치기 / 전체접기 (v0.6.0 배포 후 사용자 피드백으로 단일 토글 키로 통합)
> 최초 설계는 전체펼치기/전체접기를 서로 다른 키(`o`/`c`)에 배정했으나, 두 방향이
> 상호 배타적(한 시점엔 둘 중 하나만 의미 있음)이라는 피드백에 따라 하나의 토글 키
> (처음엔 `a`, 곧이어 `o`로 원복)로 통합했다. 아래 기준의 의도(요구되는 관찰
> 가능한 동작)는 그대로이며, "전체펼치기 키"/"전체접기 키"라는 표현만 "토글
> 키(현재 트리 상태에 따라 방향 결정)"로 대체됐다.
- 2.1: [트리 패널에 하나 이상의 폴더형 노드가 접혀 있는 상태에서 토글 키 입력] → 모든 폴더/스펙 노드가 펼쳐져 그 하위 모든 문서·파일 노드가 한 번에 보임.
- 2.2: [모든 폴더형 노드가 이미 펼쳐진 상태에서 토글 키 입력] → 모든 노드가 접혀 최상위 노드만 보임.
- 2.3: [토글 키 입력] → 그 시점에 선택돼 있던 노드의 선택 상태는 사라지지 않음(화면에서 안 보이게 접혔을 수는 있어도 선택 자체는 유지됨).
- 2.4: [트리에 노드가 하나도 없는 상태에서 토글 키 입력] → 아무 효과 없이 정상 동작이 계속됨(오류 없음).

### 3. 기존 동작 무회귀
- 3.1: [항상] → 기존 개별 노드 펼침·접힘 키(Left/Right/Enter, 클릭)는 이 기능 적용 전과 동일하게 직계 1단계만 펼치거나 접으며, 전체펼치기/전체접기 도입 이후에도 재귀적으로 동작하도록 바뀌지 않는다.
- 3.2: [항상] → `--all` CLI 플래그는 여전히 실행 시작 시점의 초기 모드를 지정하는 용도로 동작한다.

### 4. 도움말 노출
- 4.1: [도움말 화면을 염] → 모드 전환 키와 전체펼치기·전체접기 키가 다른 키 바인딩과 같은 형식으로 함께 표시된다.
