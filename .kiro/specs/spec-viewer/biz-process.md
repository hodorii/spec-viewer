## L1 Process: 스펙 열람  (id: BP-SPEC-VIEW, valueChainRef: VC-DEV-SPEC-VIEW)

개발자가 터미널에서 뷰어를 열어 스펙 트리로 현황을 파악하고, 문서를 골라 읽고, 문서 안을 이동·검색하며, 에이전트가 파일을 고치는 동안 갱신을 지켜보다가 닫는다.

```
L2-A1 Activity: 뷰어 열기  (1.1, 1.2, 1.3, 1.4)
  L3-F1 UI: 시작 화면
    L4-S1 Step: 뷰어를 실행한다
      L5-D1 DetailStep: 경로 없이 실행한다
        Logic(AST):
          - 현재 디렉터리부터 상위로 올라가며 `.kiro/` 를 찾는다
          - IF 발견 THEN 그 `.kiro/` 를 루트로 화면이 열린다
          - ELSE 개발자는 탐색한 경로가 적힌 오류를 보고, 뷰어는 열리지 않는다
      L5-D2 DetailStep: 경로를 지정해 실행한다
        Logic(AST):
          - IF 지정 경로가 `.kiro/` 이거나 그 아래에 `.kiro/` 가 있음 THEN 그것을 루트로 연다
          - ELSE 개발자는 오류를 보고, 뷰어는 열리지 않는다
    L4-S2 Step: 첫 화면을 확인한다
      - 개발자는 왼쪽 트리 패널과 오른쪽 문서 패널을 한 화면에서 본다
      - 트리 패널이 활성 상태로 시작한다

L2-A2 Activity: 스펙 현황 파악  (2.1~2.5, 2.7, 3.1~3.5, 4.1~4.4)
  L3-F2 UI: 스펙 트리 패널
    L4-S1 Step: 스펙 목록을 훑는다
      - 개발자는 스펙마다 이름과 phase 를 본다
      - 상태를 읽을 수 없는 스펙에는 경고 배지가 보인다 (다른 스펙은 영향 없음)
    L4-S2 Step: 스펙을 펼친다
      L5-D1 DetailStep: 문서 4종을 고정 순서로 본다
        Logic(AST):
          - 순서: requirements → biz-process → design → tasks
          - FOR EACH 문서:
              IF 파일 존재 THEN 승인 배지(미승인/승인됨) 표시
              ELSE 흐린 자리 표시 (배지 = 미생성)
          - IF spec.json 에 그 문서의 승인 항목 없음 THEN 배지 = 상태 없음
      L5-D2 DetailStep: tasks 진행률을 본다
        Logic(AST):
          - IF tasks.md 존재 AND 체크박스 ≥ 1 THEN `완료/전체` 표시
              IF 완료 == 전체 THEN 완료 강조
          - ELSE IF tasks.md 존재 THEN "진행률 없음"
      L5-D3 DetailStep: 추가 문서를 본다
        - 4종 뒤에 나머지 `.md` 가 파일명 순으로 이어진다
    L4-S3 Step: steering 그룹을 훑는다
      - 개발자는 스펙 목록과 분리된 steering 그룹에서 `.md` 파일을 파일명 순으로 본다
    L4-S4 Step: 트리 안에서 이동한다
      - 위/아래 이동, 펼침/접힘, 패널 전환 키로 문서 패널과 오간다

L2-A3 Activity: 문서 읽기  (2.4, 2.6, 3.6, 5.1~5.13, 8.3, 8.4, 8.5)
  L3-F3 UI: 문서 패널
    L4-S1 Step: 문서를 선택한다
      L5-D1 DetailStep: 선택 결과를 본다
        Logic(AST):
          - IF 존재하는 문서 THEN 렌더링된 본문을 본다
          - ELSE IF 미생성 자리 THEN "아직 생성되지 않음"
          - ELSE IF 경고 배지 스펙 노드 THEN spec.json 파싱 실패 원인
          - ELSE IF 읽기 권한 없음 THEN 읽기 실패 원인 (트리 탐색은 계속 가능)
          - ELSE IF 비UTF-8 구간 포함 THEN 읽을 수 있는 부분 + 대체 문자
    L4-S2 Step: 본문을 읽는다
      - 단락·리스트·인용이 패널 폭에 맞게 줄바꿈되어 보인다
      - 표는 잘리지 않고 열 폭이 배분되어 보인다
      - 코드는 구문 강조, mermaid 는 박스·화살표 텍스트 다이어그램(flowchart·er·class·state·sequence)으로, 그 밖의 유형은 소스로 보인다
      - 프론트매터는 보이지 않고, 한글 폭이 어긋나지 않는다
    L4-S3 Step: 창 크기를 바꾼다
      Logic(AST):
        - 새 폭으로 다시 그려지고, 보고 있던 위치가 유지된다
        - IF 폭이 두 패널을 둘 수 없을 만큼 좁음 THEN 활성 패널 하나만 전체 폭으로 보인다

L2-A4 Activity: 문서 안 이동·검색  (6.1~6.11)
  L3-F4 UI: 탐색 키 · TOC 팝업 · 검색 입력줄 · 상태 표시줄
    L4-S1 Step: 스크롤한다
      - 한 줄 / 반 화면 / 한 화면 / 처음·끝 단위로 이동한다
      - 상태 표시줄에서 문서 경로와 위치(백분율)를 본다
    L4-S2 Step: 헤딩으로 점프한다
      - `]` / `[` 로 다음/이전 헤딩이 패널 맨 위에 오게 이동한다
    L4-S3 Step: TOC 로 이동한다
      Logic(AST):
        - TOC 키 → 헤딩 목록 팝업 (계층 포함)
        - IF 항목 선택 THEN 팝업 닫힘 + 해당 헤딩으로 이동
        - ELSE IF 취소 THEN 팝업 닫힘, 위치 그대로
    L4-S4 Step: 검색한다
      L5-D1 DetailStep: 검색어를 입력한다
        Logic(AST):
          - `/` → 입력줄에 검색어 입력 (대소문자 무시)
          - IF 일치 ≥ 1 THEN 일치 구간 강조 + 첫 일치로 이동
          - ELSE 상태 표시줄 "일치 없음", 위치 그대로
      L5-D2 DetailStep: 일치 사이를 오간다
        Logic(AST):
          - 다음/이전 키 → 다음/이전 일치로 이동
          - IF 끝에 도달 THEN 반대쪽 끝으로 순환
      L5-D3 DetailStep: 검색을 끝낸다
        - 다른 문서를 선택하면 강조가 사라진다
    L4-S5 Step: 도움말을 본다
      - `?` 로 전체 키 목록 팝업을 보고 닫는다

L2-A5 Activity: 갱신 지켜보기  (7.1~7.6)
  L3-F5 UI: 자동 반영과 수동 새로고침
    L4-S1 Step: 읽던 문서가 바뀐다  [Event: 파일 변경]
      Logic(AST):
        - 2초 이내에 다시 그려진다
        - IF 보던 위치가 아직 있음 THEN 그 위치 유지
        - ELSE 문서 끝 표시
    L4-S2 Step: 스펙 상태가 바뀐다  [Event: spec.json / tasks.md 변경]
      - 트리의 phase·승인 배지·진행률이 바뀐 값으로 보인다
    L4-S3 Step: 스펙이 생기거나 사라진다  [Event: 디렉터리/파일 추가·삭제]
      Logic(AST):
        - 트리가 갱신된다
        - IF 선택 항목이 남아 있음 THEN 선택 유지
        - IF 읽던 문서가 삭제됨 THEN 문서 패널 "파일이 삭제됨", 트리 선택 유지
    L4-S4 Step: 감시가 안 되는 환경에서 새로고침한다  [Gateway]
      - 상태 표시줄에 감시 불가 표시가 보인다
      - 새로고침 키를 누르면 위 S1~S3 과 같은 갱신이 일어난다

L2-A6 Activity: 뷰어 닫기  (1.5, 8.6)
  L4-S1 Step: 종료 키를 누른다
    - 터미널이 실행 전 상태로 돌아온다
  L4-S2 Step: 예상하지 못한 오류로 닫힌다  [Event]
    - 터미널이 복원된 뒤 오류 메시지를 본다
```
